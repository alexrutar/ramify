# Examples

The examples are as follows.

1. [`basic.rs`](https://github.com/alexrutar/ramify/blob/master/examples/basic.rs): A basic example with an in-memory tree.
2. [`abort.rs`](https://github.com/alexrutar/ramify/blob/master/examples/abort.rs): An example highlighting iteration which may abort non-deterministically.
3. [`tree_error.rs`](https://github.com/alexrutar/ramify/blob/master/examples/tree_error.rs): An example with errors encapsulated inside the tree.
4. [`inverted.rs`](https://github.com/alexrutar/ramify/blob/master/examples/inverted.rs): An example highlighting inverted writing with the root vertex at the bottom.
5. [`merge.rs`](https://github.com/alexrutar/ramify/blob/master/examples/merge.rs): A basic example demonstrating merges using an in-memory reference-counted directed acyclic graph.
6. [`cascade.rs`](https://github.com/alexrutar/ramify/blob/master/examples/cascade.rs): A streaming example which randomly generates child nodes according to a distribution. 
7. [`cascade_merge.rs`](https://github.com/alexrutar/ramify/blob/master/examples/cascade_merge.rs): A streaming example which randomly generates child nodes, where the child nodes may coincide.
8. [`gallery.rs`](https://github.com/alexrutar/ramify/blob/master/examples/gallery.rs): A binary with built-in examples and command-line options for all configuration options.
9. [`subset.rs`](https://github.com/alexrutar/ramify/blob/master/examples/subset.rs): Randomly render a subset of a given tree.
