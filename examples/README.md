# Examples

The examples are as follows.

| File | Description |
|------|-------------|
| [`gallery.rs`](https://github.com/alexrutar/ramify/blob/master/examples/gallery.rs) | A binary with built-in examples and command-line options for all configuration options. |
| [`basic.rs`](https://github.com/alexrutar/ramify/blob/master/examples/basic.rs) | Minimal, with an in-memory tree. |
| [`abort.rs`](https://github.com/alexrutar/ramify/blob/master/examples/abort.rs) | Handle errors by aborting. |
| [`tree_error.rs`](https://github.com/alexrutar/ramify/blob/master/examples/tree_error.rs) | Display errors inside the branch diagram. |
| [`inverted.rs`](https://github.com/alexrutar/ramify/blob/master/examples/inverted.rs) | Draw the diagram with with the root vertex at the bottom. |
| [`merge.rs`](https://github.com/alexrutar/ramify/blob/master/examples/merge.rs) | Minimal example with merges using an in-memory reference-counted directed acyclic graph. |
| [`cascade.rs`](https://github.com/alexrutar/ramify/blob/master/examples/cascade.rs) | A streaming example with randomly generated children. |
| [`cascade_merge.rs`](https://github.com/alexrutar/ramify/blob/master/examples/cascade_merge.rs) | A streaming example with randomly generated children and merges. |
| [`subset.rs`](https://github.com/alexrutar/ramify/blob/master/examples/subset.rs) | Render a random subset of a given tree. |
| [`numbered.rs`](https://github.com/alexrutar/ramify/blob/master/examples/subset.rs) | A custom diagram writer implementation. |
