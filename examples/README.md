# Examples

The examples are as follows.

1. [`basic.rs`](https://github.com/alexrutar/ramify/blob/master/examples/basic.rs): A basic example with an in-memory tree.
2. [`fallible.rs`](https://github.com/alexrutar/ramify/blob/master/examples/fallible.rs): An example highlighting iteration which may fail non-deterministically.
3. [`inverted.rs`](https://github.com/alexrutar/ramify/blob/master/examples/inverted.rs): An example highlighting inverted writing with the root vertex at the bottom.
4. [`merge.rs`](https://github.com/alexrutar/ramify/blob/master/examples/merge.rs): A basic example demonstrating merges using an in-memory reference-counted directed acyclic graph.
5. [`cascade.rs`](https://github.com/alexrutar/ramify/blob/master/examples/cascade.rs): A streaming example which randomly generates child nodes according to a distribution. 
6. [`cascade_merge.rs`](https://github.com/alexrutar/ramify/blob/master/examples/cascade_merge.rs): A streaming example which randomly generates child nodes, where the child nodes may coincide.
7. [`gallery.rs`](https://github.com/alexrutar/ramify/blob/master/examples/gallery.rs): A binary with built-in examples and command-line options for all configuration options.
